# S010-凯利仓位+贝叶斯动态因子

> 创建日期：2026-07-18
> 策略类型：[x] 贝叶斯多因子 + 两层凯利仓位管理
> 状态：[x] 测试中

---

## 一、核心逻辑（大白话）

S009用LightGBM给股票打"涨/跌"的概率分，选Top20等权买入，不管市场当下靠不靠谱，
每期都是满仓20只。S010在两个地方做了根本性升级：

**1. 选股模型换成贝叶斯线性回归（BayesianRidge）**

不再只给一个点预测分数，而是对每只股票同时输出"预测未来10日收益率是多少(mu)"
和"这个预测有多大不确定性(sigma)"。就像天气预报不仅说"明天下雨"，还说"下雨概率
70%还是95%"——sigma小说明模型对这只股票信心足，sigma大说明数据里噪音多、拿不准。
每期用最近12个月数据重新训练，模型的因子权重（贝叶斯后验均值）会跟着新数据自动
漂移，这就是"贝叶斯动态因子"——旧认知(先验)遇到新证据(新数据)会更新成新认知(后验)。

**2. 两层凯利仓位管理，而不是无脑等权买20只**

- **个股层**：候选池内部，每只股票该分配多少钱，用凯利公式 `mu/sigma²` 算——
  预测收益越高、不确定性越低的股票，配得越多；反之配得越少。单只封顶20%防止
  押注过度集中在一两只票上。
- **组合层（这是最核心的创新）**：今天到底该用多少仓位（0%~100%）？不能直接
  看候选池自己的mu——候选池是"矮子里拔将军"挑出来的，它们的mu天然虚高（选择
  偏差），如果拿这个虚高数字去算凯利仓位，公式会永远告诉你"满仓干"，跟S009
  区别不大。真正的做法是：每期额外做一次"样本外验证"——把训练窗口拆成
  10个月拟合+2个月验证，看模型在没见过的验证期数据上，选出的高分股票
  历史上到底真实兑现了多少收益、稳不稳定。用这个"真实考试成绩"而不是"自我
  评价"来决定敢下多大的注——模型最近确实选得准，就多仓位；模型最近判断
  失灵，就自动降仓甚至空仓，把钱留在手里等下一个有把握的机会。

简单说：S009是"每月无脑买最看好的20只，仓位恒定100%"；S010是"每月先摸底
模型最近准不准，准就多买、不准就少买甚至空仓，同时买的这批票内部也按信心
大小分配仓位而不是平均分"。

## 二、策略参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 训练窗口 | 过去12个月滚动 | 每次调仓前用最近12个月数据重新训练模型 |
| 模型 | BayesianRidge（贝叶斯线性回归） | 标准化特征后拟合，原生输出mu(预测均值)+sigma(预测标准差) |
| 特征数 | 33个 | 与S009同源特征面板：动量5+量能4+均线偏离4+技术指标12+估值6+资金流2 |
| 候选池 | mu>0排名前30只 | 不足5只则本期空仓观望 |
| 调仓频率 | 每月初 | 月度调仓 |
| 标签窗口 | 未来10个交易日 | 回归目标改为预测未来10日收益率数值本身(而非涨跌二分类) |
| 个股层仓位 | f_i = mu_i/sigma_i², half-Kelly打五折 | 候选池内部相对配比，单只封顶20% |
| 组合层仓位 | 样本外置信度校准的Kelly敞口(0~100%) | 见下方"样本外校准"详述 |

---

## 三、样本外置信度校准（组合层仓位的核心逻辑）

| 步骤 | 说明 |
|------|------|
| 拆分 | 12个月训练窗口拆成：10个月拟合期 + 2个月验证期 |
| 验证方式 | 用拟合期数据训练一个"验证模型"，在验证期内每5个交易日取1个观测点，每个观测点选预测最高的前10%股票 |
| 真实兑现 | 这些验证期观测点都是历史上已经实现的真实fwd_ret（不构成未来函数），汇总得到oos_mu(均值)/oos_sigma(标准差) |
| 置信度衰减 | confidence = min(1, sqrt(oos_n/200))，验证样本量不足时进一步打折，避免小样本噪音误导仓位 |
| 组合仓位 | exposure = clip(oos_mu/oos_sigma² × 0.5 × confidence, 0, 1) |

这一步的本质：不相信模型对"自己精心挑出来的候选池"的自我评价（那必然虚高），
只相信模型在"没针对性挑选过的验证集"上的真实历史命中率。

## 六、风险与局限

- **样本外验证窗口只有2个月**：市场风格切换快时，2个月的"考试成绩"可能来不及
  反映最新变化，存在一定滞后性。
- **验证观测点抽样(每5个交易日1次)**：为控制10日标签窗口的重叠冗余而做的简化，
  可能损失部分信息。
- **相关系数假设固定0.30**：组合层方差估计用了简化的固定相关系数，未按实际
  行业/风格分布动态调整，是粗略近似。
- **贝叶斯线性回归是线性模型**：相比LightGBM的非线性拟合能力更弱，选股排序
  精度可能不如S009，但换来了原生的不确定性量化能力，是本策略的核心权衡取舍。
- **空仓期会产生"现金拖累"**：模型没把握时空仓虽然规避风险，但也放弃了潜在
  的beta收益，需要在回测结果里对比空仓期数和净值影响。

## 七、版本记录

| 日期 | 版本 | 变更内容 |
|------|------|----------|
| 2026-07-18 | v1.0(废弃) | 初版：组合层仓位直接用候选池自身mu算凯利敞口，导致选择偏差——候选池是"挑出来的"高mu股票，几乎永远触发满仓，98%平均仓位、最大回撤-47.9%，未能体现"贝叶斯不确定性驱动仓位"的设计初衷 |
| 2026-07-18 | v1.1(废弃) | 核心修正：组合层仓位改用"样本外置信度校准"——额外做10个月拟合+2个月验证的样本外测试，用模型在未见数据上的真实历史命中率(oos_mu/oos_sigma)决定敢下多大仓位，而非用候选池自身虚高的mu。个股层内部配比不变(仍用各自mu/sigma²排序)。样本外校准修正了选择偏差问题，但选股模型本身仍是BayesianRidge线性回归，非线性拟合能力弱，选股alpha天花板明显偏低——113期实测年化仅个位数，暴露出"仓位管理再精细，也救不了选股能力不足"的问题 |
| 2026-07-18 | v2(当前) | 选股模型换回LightGBM，但改用分位数回归(quantile regression)而非S009的二分类：同时训练q10/q50/q90三个分位数模型，q50作为预测均值mu(找回LightGBM的非线性拟合能力，向S009选股水平看齐)，用(q90-q10)/2.5632反推预测标准差sigma(80%置信区间宽度换算，替代BayesianRidge原生的不确定性输出)。两层凯利仓位管理架构不变(样本外置信度校准决定组合层敞口，mu/sigma²决定个股层配比)。113期实测：年化收益3.68%(净，毛4.30%)，胜率38.9%，最大回撤-27.6%，夏普0.30，平均总仓位51.4%，完全空仓40/113期。结论：换回LightGBM分位数回归后选股能力仍显著弱于S009的LightGBM二分类Top20(年化41.0%/夏普1.46)——用分位数损失函数间接反推的sigma不如BayesianRidge原生贝叶斯后验精确，且量化仓位后近半期数空仓/低仓，进一步压低了收益。凯利仓位管理确实把最大回撤从v1.0的-47.9%降到了-27.6%，风险控制的设计目标达成，但"选股alpha"这条腿始终没能补齐，S010系列三个版本的核心矛盾（仓位管理越做越细，选股能力却始终不如S009）在v2上依然存在 |
