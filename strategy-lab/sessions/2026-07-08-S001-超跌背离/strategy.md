## 核心逻辑

### 前置条件：熊市择时

```
上证指数距52周高点跌幅 > 15% → 熊市 → 允许开仓
否则 → 牛市/震荡 → 全部信号过滤，空仓观望
```

历史教训：大众交通在牛市中连续3次信号全部亏损。

### 信号条件（AND 关系，三项全部满足）：

#### 1. 超跌 —— 250日跌幅 > 40%

```
ret_250 = (今日收盘价 / 250天前收盘价 - 1) × 100
条件：ret_250 < -40
```

#### 2. 收敛 —— K线实体收敛比 < 75%

```
收敛比 = 近60天K线实体均值 / 前60天K线实体均值
K线实体 = |收盘价 - 开盘价| / 收盘价
条件：收敛比 < 0.75
```

抛压在衰竭。

#### 3. 背离 —— OBV 底背离

```
在250天窗口内：
  - 价格线性回归斜率 < 0（价格仍在跌）
  - OBV归一化斜率 > 0（资金在流入）
→ 底背离信号
```

价格跌但资金在进。

### 信号分级（v3新增）

| 级别 | 条件 | 含义 |
|------|------|------|
| ★★★ 重仓 | 三条件全满足 + 60日主力资金净流入趋势向上 | 资金流入确认 |
| ★★☆ 标准 | 三条件全满足，但资金流向未确认 | 仅OBV反转 |

### 信号去重（v3新增）

同股票20天内不重复出信号（`SIGNAL_GAP = 20`），信号写入 `signal_history` 表避免重复提示。

## 已知局限

1. 熊市择时依赖上证指数52周高点判断，有滞后性
2. 牛市阶段完全空仓，可能错过结构性机会
3. OBV底背离可能在下跌中继出现假信号
4. 80个交易日持仓周期较长
5. 资金流向数据可能存在延迟或缺失（部分股票无moneyflow数据）
6. 信号去重20天间隔可能错过加仓机会
